¿Qué afirmación es FALSA?


a.  Las reglas CSS se pueden escribir como contenido de un elemento
    'link'.

b.  Las reglas CSS se pueden escribir como contenido de un elemento
    'style'.

c.  La misma regla CSS se puede aplicar a varios elementos. Un mismo
    elemento puede recibir el efecto de varias reglas.

d.  En una regla CSS el selector indica a qué elementos se aplica la
    regla, esto es, 'para estos elementos, este atributo tiene tal
    valor'.
